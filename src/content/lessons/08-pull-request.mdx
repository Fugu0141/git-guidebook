## 今回の場面

作業Branchで完成した変更を、基準のmainへ取り込む前に確認する場所が必要です。Pull Requestは「このBranchの変更をmainへ取り込みたい」という提案で、差分・理由・確認結果をまとめます。作成しただけではmainは変わりません。

## 今回できるようになること

- 作業Branchで変更をCommit・Pushできる
- baseとcompareを正しく選べる
- 差分と説明を確認してPull Requestを作れる
- Pull Request作成とMergeを区別できる

## まず簡単に説明

Pull Requestは「この変更をmainへ取り込んでよいですか」と提案し、差分を確認するGitHub上のページです。作成した時点ではmainへ取り込まれません。

## もう少し正確に

baseは変更を受け取る側、compareは変更を持ってくる側です。今回はbaseがmain、compareが `add-learning-goal` です。Pull RequestはGitのCommitを新しく作る操作ではなく、2つのBranchの比較と会話をGitHub上に結び付けます。

<OptionalDetails summary="説明欄に書くこと">
  変更内容、変更した理由、確認方法、特に見てほしい点を書きます。一人開発でも未来の自分が意図を思い出せる記録になります。
</OptionalDetails>

## 操作前

まず `add-learning-goal` BranchでREADMEに学習目標を追加し、Commit、Pushします。

1. Current Branchが `add-learning-goal` であることを確認します。
2. README末尾へ `- CommitとPushの違いを説明する` を追加して保存します。
3. 差分を確認し、Summaryを `Add learning goal` としてCommitします。
4. **Push origin** を選びます。

## 一緒に操作

1. GitHub Desktopの **Create Pull Request** を選び、ブラウザを開きます。
2. GitHub上で **base: main**、**compare: add-learning-goal** になっていることを確認します。
3. **Files changed** で、READMEに意図した1行だけが追加されているか確認します。
4. タイトルに `Add learning goal` と入力します。
5. 説明に「練習用READMEへ学習目標を追加しました」と「確認: 差分を確認済み」を書きます。
6. **Create pull request** を選びます。

## 内部で起きたこと

Gitの履歴そのものを進める操作ではなく、GitHub上にbaseとcompareの差分を結び付けたPull Requestが作られました。Mergeするまでは2つのBranchが別の地点を指します。

## 対応するGitコマンド

Pull Request作成はGitHubの機能です。次のコマンドは、その前提となる変更・Commit・Pushに対応します。

<CommandGuide
  directory="git-guidebook-practice作業フォルダの中で実行します。"
  prerequisite="add-learning-goal Branchにいて、READMEの学習目標を保存済みであること。"
  effect="READMEの変更を作業BranchへCommitし、対応するGitHub上のBranchへPushします。mainは変わりません。"
  desktopEquivalent="ChangesでCommitし、Push originを選ぶ操作です。Pull Request自体はブラウザで作ります。"
  output="Commit結果の後、Pushでadd-learning-goal -> add-learning-goalと表示されれば送信済みです。"
  firstCheck="Push先がmainに見える場合は実行せず、現在のBranchを確認します。nothing to commitなら保存と差分を確認します。"
>
  <pre>
    <code>{`git add README.md
git commit -m "Add learning goal"
git push`}</code>
  </pre>
</CommandGuide>

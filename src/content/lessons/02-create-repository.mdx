## 今回の場面

練習用プロジェクトを始めるため、まずGitHub上に履歴の置き場所を作ります。仕事や授業の本物のリポジトリではなく、この教材だけで使う `git-guidebook-practice` を新しく用意します。

今回はブラウザ上のGitHubだけを操作します。端末内の作業フォルダとローカルリポジトリは、次のCloneで作ります。

## 今回できるようになること

- Repository name、Description、Public / Private、READMEの意味を説明できる
- 公開してよい情報かを確認してから公開範囲を選べる
- GitHub上にREADMEを含む練習用リモートリポジトリを作れる
- 作成直後に変わった場所と、まだ存在しない場所を見分けられる

## まず簡単に説明

GitHub上のリポジトリは、プロジェクトのファイルとPushされた履歴を置く場所です。最初にREADME付きで作っておくと、GitHub上に最初のCommitが1つできます。次のレッスンでは、その履歴を端末へCloneします。

<Callout type="warning" title="公開範囲は作成前に確認">
  Publicはインターネット上の誰でも閲覧できます。個人情報、授業課題の未公開内容、仕事の情報、パスワードやトークンは入れません。少しでも迷う場合はPrivateを選んで学習できます。
</Callout>

## もう少し正確に

GitHubで「Add a README file」を選んで作成すると、空の置き場所だけではなく、READMEを追加した最初のCommitを含むリモートリポジトリができます。READMEは、リポジトリの目的や使い方を説明するファイルです。

<OptionalDetails summary=".gitignoreとLicenseを今回は選ばない理由">
  `.gitignore`
  はGitで追跡しないファイルを指定します。Licenseは他の人がコードや文章を利用できる条件を示します。どちらも用途に応じた判断が必要なので、この練習では追加しません。特に実プロジェクトのLicenseは、所有者や組織が決めるものです。
</OptionalDetails>

## 一緒に操作

1. ブラウザでGitHubにサインインし、画面右上の **＋** から **New repository** を開きます。
2. **Repository name** に `git-guidebook-practice` と入力します。
3. **Description** に `Git Guidebookの練習用リポジトリ` と入力します。
4. 公開してよい練習内容だけを入れる場合は **Public**、外から見せない場合は **Private** を選びます。
5. **Add a README file** をオンにします。
6. `.gitignore` とLicenseは今回は **None** のままにします。
7. リポジトリ名、公開範囲、READMEの3点を声に出して確認します。
8. **Create repository** を選びます。

## 自分でやってみる

<PracticeTask title="Clone前の現在地を自分で確認する">
  作成したリポジトリの **Code** ボタンを開き、HTTPSのURLに `git-guidebook-practice` が含まれることだけ確認してください。まだCloneは押しません。

そのあと、「いま存在するのはGitHub上のリモートリポジトリだけ。端末側はまだない」と声に出すかメモします。Codeメニューに秘密情報は表示されませんが、URLを共有するときは自分のユーザー名が含まれることを意識してください。

</PracticeTask>

## 対応するGitコマンド

GitHub上にリポジトリを新規作成する操作は、Gitそのもののコマンドではありません。次のコマンドは、作成済みリモートを変更せずに確認したい人だけ実行します。

<CommandGuide
  directory="どのフォルダでも実行できます。"
  prerequisite="作成したリポジトリのHTTPS URLが分かること。Privateの場合は認証を求められることがあります。"
  effect="リモートにあるBranchやCommitの参照情報を読み取ります。Clone、Commit、Pushは行わず、3つの場所を変更しません。"
  desktopEquivalent="GitHubのリポジトリ画面を開いて、リモートが存在することを確認する操作に近い読み取り専用の確認です。"
  output="英数字の長いCommit IDと HEAD や refs/heads/main が表示されれば、リモートの履歴を読み取れています。"
  firstCheck="Not FoundならURLのユーザー名とリポジトリ名を確認します。認証エラーなら何度も入力せず、Public / PrivateとGitHubの認証状態を確認します。"
>
  ```bash git ls-remote https://github.com/USER/git-guidebook-practice.git ```
</CommandGuide>

## できるようになったこと

- 名前、公開範囲、READMEを確認して練習用リポジトリを作成できる
- GitHubがREADMEを含む最初のCommitを作ったと説明できる
- 作成直後はGitHub上だけが変わり、端末側はまだ存在しないと判断できる
